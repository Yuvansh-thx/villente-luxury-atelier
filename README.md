# Villente — Luxury Turnkey Architecture & Interior Atelier

An ultra-luxury editorial web experience for **Villente**, an internationally acclaimed atelier specializing in worldwide turnkey interior architecture, high-end residential commissions, and bespoke materials.

Designed with haute-couture editorial typography (Didone serifs, Pinyon Script accents, geometric sans), layered 3D depth, interactive materiality explorers, and harmonic Web Audio soundscapes. Fully adaptable across **Phone**, **Tablet**, and **PC** screens.

---

## ✨ Features

- **Multi-Device Responsive Design**:
  - **Phone (320px – 768px)**: Adaptive masthead lettering, single-column architectural spreads, touch-scrolling swatches, touch-friendly carousel reel controls, and 16px input fields to prevent iOS auto-zoom.
  - **Tablet (768px – 1024px)**: Balanced 2-column and 3-column editorial spreads with landscape villa features and touch-optimized layout.
  - **PC & Ultra-Wide (1025px – 1920px+)**: Custom magnetic dual-ring cursor, 3D mouse parallax on masthead and layered frames, multi-axis floating scroll parallax, and iconic fixed editorial navigation.
- **Editorial Mobile Navigation Drawer**: Sleek full-screen navigation drawer with quick section jumps, active section tracking, and ambient atmosphere controls.
- **Interactive Project Reel Carousel**: Smooth horizontal snapping showcase with previous/next controls, dot indicators, and full-screen case study drawer modals.
- **Studio Material Swatch Explorer**: Interactive tactile material switcher showcasing rare marbles, virgin cashmere bouclé, fumed Belgian oak, unlacquered champagne brass, and Murano cast glass.
- **Ambient Atmosphere Synthesizer**: Built using the Web Audio API with multi-oscillator low-frequency drones, crystal chimes, and synchronized controls.
- **Bespoke Commission Inquiry**: Confidential client intake form with scope selector and automated inquiry tracking.

---

## 🛠️ Tech Stack

- **HTML5 & Modern Semantic Web**: Clean editorial DOM structure, accessible ARIA attributes, and smooth anchor routing.
- **CSS3 Modern Architecture**: Custom properties design system, CSS Grid, Flexbox, `clamp()` fluid typography, and viewport-fit safe area insets.
- **Modern JavaScript (ES Modules)**: Object-oriented architecture, IntersectionObserver scroll-spy, Web Audio API, and touch-aware event listeners.
- **Vite**: Ultra-fast next-generation frontend tooling.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Yuvansh-thx/villente-luxury-atelier.git
   cd villente-luxury-atelier
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```
